The native port is gaining INI-based keyboard/mouse and SDL gamepad bindings. Add an in-game controls menu so players can configure these without editing a file.

Scope:
- List movement, camera, and every gameplay/menu action with the current keyboard/mouse and controller bindings.
- Capture a new key, mouse button, gamepad button, axis, or hat; support unbind, cancel, duplicate/conflicting bindings, and restore defaults.
- Persist changes to the same input.ini used at startup; apply them immediately through the input configuration reload path.
- Expose mouse sensitivity/invert, stick deadzones, trigger threshold, controller look invert, and automatic/forced prompt family.
- Show the connected controller name and explain how to load an SDL mapping for unrecognized devices.
- Navigate and operate the menu with either keyboard/mouse or controller, with focus-safe cancel and no input leaking into gameplay while capturing a binding.
- Use the active device's Kenney input icons, including rebound controls, and update when the last input device changes.

Acceptance: change a keyboard and controller binding in the menu, resume gameplay and use both immediately, restart and verify persistence, restore defaults, and test hotplug/focus loss while the binding capture dialog is open.
