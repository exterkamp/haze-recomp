Haze Recomp

Experimental browser port under development. Rendering and gameplay are not yet validated.

Select your extracted BLUS30094 disc directory (containing PS3_GAME), including a decrypted EBOOT.ELF. Files are read locally; they are not uploaded.

Checking browser support…

This Wasm64 build requires a 64-bit browser, shared memory and approximately 8 GB of addressable Wasm memory.

WASD: move · Mouse: look (click to capture) · Space: confirm/jump · Enter: Start · E: square · R: triangle · X: circle · Arrow keys: menus · F1: release mouse. Standard gamepads are supported.
